# Datoviz/Vulkan Volume Rendering Backend Plan

This repository contains the architecture and implementation details for a dedicated Datoviz/Vulkan rendering engine.
It serves as an optional, validated rendering backend for CellQuant.

Please see the [Datoviz/Vulkan Volume Rendering Backend Plan](DATOVIZ_VULKAN_BACKEND_PLAN.md) for full architectural details, API boundaries, and integration guidelines.
